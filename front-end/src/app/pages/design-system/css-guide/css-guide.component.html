Design system Aero

Classes CSS

Estilize divs e elementos HTML nativos usando a mesma base visual dos componentes Aero.

Como aplicar

Os estilos já são carregados globalmente por src/styles.css, que importa src/aero.css. Dentro deste frontend, basta adicionar as classes ao HTML; não é necessário importar um componente Angular.

Use sempre a classe base junto de suas variações: aero-button aero-button--primary, por exemplo. Quando houver CSS complementar, copie-o para o arquivo de estilos da sua página.

As classes cuidam da aparência. Validação, envio de formulários, eventos e chamadas à API continuam sob responsabilidade da página. Em formulários Angular, mantenha os imports de FormsModule ou ReactiveFormsModule quando usados.
